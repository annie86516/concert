FIRST-TIME SETUP

先連接免費雲端資料庫

只需設定一次。完成後下載新的 index.html，再把它上傳到 GitHub Pages。

1

建立 Supabase 免費專案

前往 supabase.com 建立專案，等待資料庫啟用。

2

執行資料庫設定

在 Supabase 的 SQL Editor 開啟 New query，貼上同資料夾的 supabase-setup.sql，按 Run。

3

填入連線資訊

在 Supabase 專案的 Connect 視窗，複製 Project URL 與 Publishable key。

不要填 Secret key 或 service_role key。Publishable key 本來就可放在網頁中，實際資料仍由邀請碼與密碼保護。
